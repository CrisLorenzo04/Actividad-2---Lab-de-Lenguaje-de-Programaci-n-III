102 Etiquetas HTML

N° Nombre de la Etiqueta Descripción Ejemplo de Uso Elemento Adicional
1 <a> Define un hipervínculo. Se utiliza para enlazar una página a otra o un recurso. <a href="https://www.example.com">Visita Ejemplo</a> Se puede agregar el atributo target="_blank" para abrir el enlace en una nueva pestaña.
2 <p> Define un párrafo de texto. <p>Este es un párrafo.</p> Puede contener otros elementos en línea como <a>, <strong>, <em>.
3 <img> Incrusta una imagen en la página. <img src="imagen.jpg" alt="Descripción de la imagen"> Importante incluir el atributo alt para accesibilidad.
4 <div> Define una sección o contenedor en el documento. <div>Contenido del div</div> Usualmente usado para aplicar estilos o agrupar otros elementos.
5 <h1> Define el encabezado más importante en la página. <h1>Este es un Encabezado</h1> Los encabezados van desde <h1> (más importante) hasta <h6> (menos importante).
6 <h2> Define un encabezado de segundo nivel. <h2>Subtítulo</h2> Usado para secciones principales dentro del contenido.
7 <h3> Define un encabezado de tercer nivel. <h3>Sub-subtítulo</h3> Útil para organizar jerarquías de contenido.
8 <h4> Define un encabezado de cuarto nivel. <h4>Encabezado menor</h4> Menos prominente que h1-h3.
9 <h5> Define un encabezado de quinto nivel. <h5>Encabezado pequeño</h5> Usado para secciones muy específicas.
10 <h6> Define el encabezado menos importante. <h6>Encabezado mínimo</h6> El nivel más bajo de jerarquía de encabezados.
11 <ul> Define una lista no ordenada (con viñetas). <ul><li>Item 1</li><li>Item 2</li></ul> Los items se definen con <li>.
12 <ol> Define una lista ordenada (numerada). <ol><li>Primero</li><li>Segundo</li></ol> Los números se generan automáticamente.
13 <li> Define un item de una lista. <li>Elemento de lista</li> Se usa dentro de <ul> o <ol>.
14 <table> Define una tabla. <table><tr><td>Dato</td></tr></table> Contiene filas (<tr>) y celdas (<td> o <th>).
15 <tr> Define una fila en una tabla. <tr><td>Celda 1</td><td>Celda 2</td></tr> Debe estar dentro de <table>.
16 <td> Define una celda de datos en una tabla. <td>Contenido de celda</td> Se usa dentro de <tr>.
17 <th> Define una celda de encabezado en una tabla. <th>Encabezado</th> El texto aparece en negrita y centrado por defecto.
18 <strong> Define texto con importancia fuerte (negrita). <strong>Texto importante</strong> Similar a <b> pero con significado semántico.
19 <em> Define texto enfatizado (cursiva). <em>Texto enfatizado</em> Similar a <i> pero con significado semántico.
20 <b> Define texto en negrita. <b>Texto en negrita</b> Sin significado semántico especial.
21 <i> Define texto en cursiva. <i>Texto en cursiva</i> Sin significado semántico especial.
22 <u> Define texto subrayado. <u>Texto subrayado</u> Usar con precaución para no confundir con enlaces.
23 <s> Define texto tachado. <s>Texto tachado</s> Indica contenido que ya no es relevante.
24 <small> Define texto más pequeño. <small>Texto pequeño</small> Usado para notas legales o comentarios.
25 <mark> Define texto resaltado/marcado. <mark>Texto resaltado</mark> Aparece con fondo amarillo por defecto.
26 <del> Define texto eliminado. <del>Texto eliminado</del> Muestra una línea sobre el texto.
27 <ins> Define texto insertado. <ins>Texto insertado</ins> Muestra texto subrayado.
28 <sub> Define texto subíndice. H<sub>2</sub>O Usado en fórmulas químicas.
29 <sup> Define texto superíndice. x<sup>2</sup> Usado en expresiones matemáticas.
30 <blockquote> Define una cita en bloque. <blockquote>Cita larga</blockquote> Usado para citas de otras fuentes.
31 <q> Define una cita corta en línea. <q>Cita corta</q> Agrega comillas automáticamente.
32 <abbr> Define una abreviatura. <abbr title="HyperText Markup Language">HTML</abbr> Muestra el título completo al pasar el mouse.
33 <address> Define información de contacto. <address>Email: ejemplo@correo.com</address> Usado en footers o secciones de contacto.
34 <cite> Define el título de una obra. <cite>Título del libro</cite> Aparece en cursiva por defecto.
35 <code> Define código de programación. <code>console.log("Hola")</code> Usa fuente monoespaciada.
36 <pre> Define texto preformateado. <pre>Texto con espacios y saltos</pre> Mantiene el formato original.
37 <kbd> Define entrada de teclado. <kbd>Ctrl+C</kbd> Usado para atajos de teclado.
38 <samp> Define salida de muestra de programa. <samp>Error 404</samp> Usado para mostrar resultados.
39 <var> Define una variable. <var>x</var> = 5 Usado en contextos matemáticos o de programación.
40 <form> Define un formulario. <form action="/enviar" method="post"></form> Contiene elementos de entrada de datos.
41 <input> Define un campo de entrada. <input type="text" name="nombre"> Puede ser text, password, email, number, etc.
42 <textarea> Define un área de texto multilínea. <textarea rows="4" cols="50"></textarea> Para textos largos como comentarios.
43 <button> Define un botón. <button type="button">Click</button> Puede estar dentro o fuera de un formulario.
44 <select> Define una lista desplegable. <select><option>Opción 1</option></select> Contiene elementos <option>.
45 <option> Define una opción en una lista desplegable. <option value="1">Opción 1</option> Se usa dentro de <select>.
46 <label> Define una etiqueta para un elemento de formulario. <label for="email">Email:</label> Mejora la accesibilidad del formulario.
47 <fieldset> Agrupa elementos relacionados en un formulario. <fieldset><legend>Datos personales</legend></fieldset> Dibuja un borde alrededor del grupo.
48 <legend> Define un título para un fieldset. <legend>Información</legend> Se usa dentro de <fieldset>.
49 <datalist> Define una lista de opciones predefinidas. <input list="navegadores"><datalist id="navegadores"><option value="Chrome"></datalist> Proporciona autocompletado.
50 <output> Define el resultado de un cálculo. <output name="resultado">0</output> Usado con JavaScript para mostrar resultados.
51 <header> Define el encabezado de una página o sección. <header><h1>Título</h1></header> Elemento semántico de HTML5.
52 <footer> Define el pie de página de una página o sección. <footer><p>Copyright 2026</p></footer> Elemento semántico de HTML5.
53 <nav> Define una sección de navegación. <nav><a href="/">Inicio</a></nav> Usado para menús de navegación.
54 <main> Define el contenido principal del documento. <main><p>Contenido principal</p></main> Solo debe haber uno por página.
55 <section> Define una sección temática del documento. <section><h2>Sección</h2></section> Elemento semántico de HTML5.
56 <article> Define contenido independiente y autocontenido. <article><h2>Artículo</h2></article> Usado para posts de blog, noticias, etc.
57 <aside> Define contenido relacionado pero separado. <aside><p>Información lateral</p></aside> Usado para sidebars o contenido complementario.
58 <details> Define detalles adicionales que el usuario puede mostrar/ocultar. <details><summary>Ver más</summary><p>Contenido</p></details> Elemento interactivo nativo.
59 <summary> Define el encabezado visible de un elemento details. <summary>Click para expandir</summary> Se usa dentro de <details>.
60 <dialog> Define un cuadro de diálogo o ventana modal. <dialog open><p>Mensaje</p></dialog> Elemento de HTML5 para modales nativos.
61 <figure> Define contenido autónomo como una imagen con leyenda. <figure><img src="foto.jpg"><figcaption>Leyenda</figcaption></figure> Usado con <figcaption>.
62 <figcaption> Define la leyenda de una figura. <figcaption>Descripción de la imagen</figcaption> Se usa dentro de <figure>.
63 <picture> Define un contenedor para múltiples fuentes de imagen. <picture><source srcset="img.webp"><img src="img.jpg"></picture> Para imágenes responsivas.
64 <source> Define recursos multimedia para elementos picture, audio o video. <source src="video.mp4" type="video/mp4"> Se usa dentro de <picture>, <audio> o <video>.
65 <audio> Define contenido de audio. <audio controls><source src="audio.mp3"></audio> El atributo controls muestra los controles de reproducción.
66 <video> Define contenido de video. <video controls width="400"><source src="video.mp4"></video> Soporta múltiples formatos con <source>.
67 <track> Define pistas de texto para elementos de media. <track src="subtitulos.vtt" kind="subtitles"> Usado para subtítulos en videos.
68 <canvas> Define un área para dibujar gráficos con JavaScript. <canvas id="miCanvas" width="200" height="100"></canvas> Requiere JavaScript para dibujar.
69 <svg> Define gráficos vectoriales escalables. <svg width="100" height="100"><circle cx="50" cy="50" r="40"/></svg> Gráficos que no pierden calidad al escalar.
70 <iframe> Define un marco en línea para incrustar otra página. <iframe src="https://example.com" width="500" height="300"></iframe> Usado para incrustar videos, mapas, etc.
71 <embed> Define un contenedor para contenido externo. <embed src="archivo.swf" width="400" height="300"> Usado para plugins externos.
72 <object> Define un objeto incrustado. <object data="archivo.pdf" width="400" height="300"></object> Alternativa más flexible que <embed>.
73 <param> Define parámetros para un objeto. <param name="autoplay" value="true"> Se usa dentro de <object>.
74 <map> Define un mapa de imagen del lado del cliente. <map name="miMapa"><area shape="rect" coords="0,0,100,100"></map> Usado con <area> para crear zonas clickeables.
75 <area> Define un área dentro de un mapa de imagen. <area shape="circle" coords="50,50,30" href="link.html"> Se usa dentro de <map>.
76 <span> Define un contenedor en línea. <span style="color:red">Texto rojo</span> Usado para aplicar estilos a partes específicas de texto.
77 <br> Define un salto de línea. Línea 1<br>Línea 2 Etiqueta vacía (no tiene cierre).
78 <hr> Define una línea horizontal temática. <hr> Usado para separar contenido.
79 <wbr> Define una oportunidad de salto de línea. PalabraMuyLarga<wbr>QuePuedeRomperse</wbr> El navegador decide si romper la línea ahí.
80 <meta> Define metadatos del documento. <meta charset="UTF-8"> Se usa en el <head> del documento.
81 <link> Define la relación entre el documento y un recurso externo. <link rel="stylesheet" href="estilos.css"> Usado para enlazar hojas de estilo.
82 <style> Define estilos CSS internos. <style>body { background: white; }</style> Se coloca en el <head>.
83 <script> Define código JavaScript. <script>alert("Hola");</script> Puede estar en el head o al final del body.
84 <noscript> Define contenido alternativo si JavaScript está deshabilitado. <noscript><p>Activa JavaScript</p></noscript> Se muestra solo si JS no está disponible.
85 <title> Define el título del documento. <title>Mi Página</title> Aparece en la pestaña del navegador.
86 <base> Define la URL base para todos los enlaces relativos. <base href="https://www.example.com/"> Se usa en el <head>.
87 <html> Define la raíz del documento HTML. <html lang="es"></html> Contiene todo el documento.
88 <head> Define la sección de metadatos del documento. <head><title>Título</title></head> Contiene meta, title, link, style, script.
89 <body> Define el cuerpo del documento. <body><p>Contenido visible</p></body> Contiene todo el contenido visible.
90 <template> Define contenido que se mantiene oculto pero puede ser clonado con JavaScript. <template><p>Contenido plantilla</p></template> No se renderiza hasta ser activado con JS.
91 <slot> Define un marcador de posición en un componente web. <slot name="header"></slot> Usado en Web Components.
92 <progress> Define una barra de progreso. <progress value="70" max="100">70%</progress> Muestra el progreso de una tarea.
93 <meter> Define una medida escalar dentro de un rango conocido. <meter value="0.6">60%</meter> Usado para mostrar niveles como uso de disco.
94 <time> Define una fecha/hora específica. <time datetime="2026-09-25">25 de septiembre</time> El atributo datetime tiene el formato máquina-legible.
95 <data> Asocia contenido con un valor legible por máquina. <data value="123">Producto 123</data> Similar a <time> pero para datos generales.
96 <ruby> Define anotaciones ruby (para idiomas asiáticos). <ruby>漢<rt>kan</rt></ruby> Usado para mostrar pronunciación.
97 <rt> Define la anotación de pronunciación en ruby. <rt>pronunciación</rt> Se usa dentro de <ruby>.
98 <rp> Define qué mostrar en navegadores que no soportan ruby. <rp>(</rp><rt>texto</rt><rp>)</rp> Proporciona fallback para navegadores antiguos.
99 <bdi> Aísla una parte del texto que podría formatearse en dirección diferente. <bdi>Texto en árabe</bdi> Útil para texto bidireccional.
100 <bdo> Sobrescribe la dirección actual del texto. <bdo dir="rtl">Texto de derecha a izquierda</bdo> Usado para forzar dirección de texto.
101 <data> Conecta contenido con un valor legible por máquina. <data value="456">Código 456</data> El atributo value contiene el dato máquina-legible.
102 <search> Define una sección de búsqueda (HTML5.2+). <search><input type="search"></search> Elemento semántico para funcionalidad de búsqueda.
